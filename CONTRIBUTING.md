# Guia de Contribuição

Obrigada por considerar contribuir com este projeto 💜

## Princípios deste repositório
- Clareza na comunicação.
- Respeito e colaboração.
- Melhorias pequenas, úteis e contínuas.

## Como contribuir
1. Faça um fork do repositório.
2. Crie uma branch para sua melhoria:
   ```bash
   git checkout -b feat/minha-melhoria
   ```
3. Faça alterações objetivas e com contexto.
4. Garanta que o app continua executando normalmente.
5. Abra um Pull Request descrevendo:
   - problema
   - solução proposta
   - impacto esperado

## Padrão de commits (sugestão)
- `feat:` nova funcionalidade
- `fix:` correção de bug
- `docs:` melhoria de documentação
- `refactor:` refatoração sem alteração de comportamento

Exemplo:
```text
docs: reforça identidade do projeto e melhora instruções de uso
```

## Boas práticas para gerar valor
- Documente mudanças visíveis no README.
- Prefira PRs pequenos e fáceis de revisar.
- Conecte cada mudança a uma dor real de usuário.
- Se possível, proponha próximos passos no roadmap.
